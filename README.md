# Learn DSA

A comprehensive repository for learning **Data Structures and Algorithms (DSA)** from the ground up. This is a structured course designed to take you from programming fundamentals all the way through algorithmic problem-solving.

## 📚 Overview

This repo provides a step-by-step learning path for mastering DSA concepts. Each module includes:
- **📝 Notes**: Detailed explanations with diagrams and examples
- **💻 Code**: Implementation examples and practice problems
- **📊 Visualizations**: Images and diagrams to understand concepts better

## 📂 Course Structure

### [00-introduction](./00-introduction/)
**Getting Started with DSA**
- Introduction to the course
- Prerequisites and foundational concepts
- How to approach DSA learning

### [01-warmup](./01-warmup/)
**Programming Fundamentals**
- **Programming 101**: Types, variables, and data structures in JavaScript
  - Basic data types: numbers, strings, booleans
  - Arrays and Objects
  - Working with collections
- **Functions & Control Flow**: Functions, if-else statements, and logical flow
- **Notes & Code**: Practical examples to reinforce fundamentals

### [02-time-space-complexity](./02-time-space-complexity/)
**Time & Space Complexity Analysis**
- **Time Complexity**: Understanding how algorithm performance scales with input size
  - Big O notation (O(1), O(n), O(n²), etc.)
  - Identifying complexity by counting loops
  - Real-world examples and analysis techniques
- **Space Complexity**: Understanding memory usage patterns
- **Code Examples**: Practice identifying complexity in real code

## 🎯 Learning Path

Follow the modules in order:

```
00-introduction → 01-warmup → 02-time-space-complexity → ...
```

Each module builds on the previous one, so it's recommended to complete them sequentially.

## 🚀 Getting Started

1. Clone or download this repository
2. Start with [00-introduction](./00-introduction/) to understand the course structure
3. Work through [01-warmup](./01-warmup/) to refresh programming fundamentals
4. Continue with [02-time-space-complexity](./02-time-space-complexity/) to learn complexity analysis
5. Study the notes and try the code examples

## 📋 Prerequisites

- Basic understanding of JavaScript (or a similar programming language)
- Text editor or IDE (VS Code recommended)
- Curiosity and patience for learning!

## 💡 How to Use This Repository

1. **Read the Notes**: Start with the `notes.md` file in each module
2. **Study the Examples**: Look at the code examples in the `codes/` folder
3. **Practice**: Try implementing the concepts yourself
4. **Understand Diagrams**: Pay attention to visual explanations in the notes

## 📖 Recommended Study Tips

- Don't rush through modules—understanding is key
- Try to explain concepts in your own words
- Write code by hand first, then type it
- Practice similar problems from different sources
- Review previously learned concepts regularly
